# L4: 动作规范性评分模块

## 目标
对单个动作执行质量进行评分（0-100分），不依赖L3的动作分类。

## 评分维度

### 1. 关节角度规范性 (30分)
- 膀关节角度范围 (0-180°)
- 膝关节弯曲角度
- 肘关节角度
- 距离标准动作模板的偏差

### 2. 动作幅度 (25分)
- 身体中心移动距离
- 四肢活动范围
- 对比标准模板（如Squat需要臀部下降至膝盖高度）

### 3. 左右对称性 (20分)
- 左右手臂角度差异
- 左右腿部角度差异
- 身体倾斜（肩部/臀部水平差）

### 4. 动作节奏与平滑性 (15分)
- 速度曲线平滑性（加速度方差）
- 动作周期一致性（如波比跳跃）

### 5. 姿态稳定性 (10分)
- 重心在支撑面内
- 身体摇晃角度

## 技术路线

### 阶段1: 基于GT 3D数据设计规则
- 使用Human3.6M的GT 3D姿态
- 针对15个动作设计具体评分规则
- 不依赖L2/L3，完全绯过关节对齐问题

### 阶段2: 在L2输出上验证
- 使用L2的P1=48.11mm输出
- 评估角度误差（1-2°）对评分的影响
