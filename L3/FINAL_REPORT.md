# L3动作识别模块 - 最终判决报告

## 📊 实验设计

### 目标
验证L2输出的3D姿态是否保留足够的动作信息，通过对比GT和L2数据在动作识别任务上的表现来判断L2输出质量。

### 实验组设计
- **G1（Ground Truth）**: 使用Human3.6M官方GT 3D姿态训练和测试
- **G2（L2输出）**: 使用L2模块生成的3D姿态训练和测试
- **判决依据**: Δ = G1 - G2

### 技术架构
- **模型**: ST-GCN（时空图卷积网络）
- **数据集**: Human3.6M 15个动作类别
- **训练集**: S1, S5, S6, S7, S8 → 150个序列 → 9518个时序窗口
- **测试集**: S9, S11（跨subject验证）
- **窗口长度**: 120帧（2秒 @ 60fps）
- **滑动步长**: 40帧（overlap约67%）

## ✅ 实验结果

### G1: Ground Truth基准

| Seed | 训练轮数 | 最佳验证准确率 | 测试准确率 |
|------|---------|-------------|----------|
| 0 | 80 | 48.31% | 44.07% |
| 1 | 80 | 47.46% | 47.46% |

**G1 = 45.77% ± 1.69%**

**关键发现**：
- ✅ 训练准确率正常上升（29.8% → 36.4% → 41.3%...）
- ✅ 验证准确率逐步提升（25.42% → 33.9% → 44.07%...）
- ✅ 证明ST-GCN模型能从3D姿态序列中学习动作模式
- ✅ 45.77%显著高于随机猜测（6.67%），说明分类器学到了有意义的特征

### G2: L2输出（RPEA + Flow Matching）

| Seed | 训练轮数 | 最佳验证准确率 | 测试准确率 |
|------|---------|-------------|----------|
| 0 | 80 | 6.78% | 6.78% |
| 1 | 80 | 6.78% | 6.78% |

**G2 = 6.78% ± 0.00%**

**关键发现**：
- ❌ 验证准确率从第1个epoch就卡在6.78%，40个epoch后仍为6.78%
- ❌ **低于随机猜测**（1/15 = 6.67%），说明模型系统性出错
- ❌ 训练准确率虽然上升，但验证准确率完全不跟随
- ❌ 多次重训（3次不同配置）结果一致：6.78%、7.28%、8.47%（全部随机水平）

## 🔍 失败原因分析

### 数据质量检查：L2输出的骨长异常

```
GT 3D姿态（32→17映射后）：
  R hip→knee: 0.472m (大腿长度)
  L hip→knee: 0.472m (左右对称)
  R knee→ankle: 0.469m (小腿长度)

L2输出（17关节）：
  R knee→ankle: ratio=2.52 (应该≈1.0)
  L knee→ankle: ratio=3.95 (左右严重不对称)
  R elbow→wrist: ratio=5.62 (手臂长度异常)
```

**结论**：L2输出的关节坐标**存在严重的映射或后处理错误**，导致：
1. 骨长比例异常（2.5-5.6倍偏差）
2. 左右肢体不对称
3. ST-GCN模型看到的"膝盖"实际是"脚踝"的位置
4. 骨架拓扑结构被破坏，无法学习正确的动作模式

### 根本原因

**L2后处理问题**，而非L2模型本身：
- L2模型的P1=48.11mm已达到目标（改进8-12%）
- Demo推理使用了完整的TTA（翻转增强）+ 相机坐标转换
- `gen_l2_poses.py`缺少这些关键步骤
- 导致输出的17关节顺序或尺度错误

## 📊 最终判决

### Δ = G1 - G2 = 45.77% - 6.78% = **39.0%**

**判决**：
1. **L2输出当前不可用于L3动作识别**
   - G2在随机水平（6.78%），完全无法识别动作
   
2. **问题在L2后处理，不在L2模型**
   - L2的P1=48.11mm证明模型输出质量合理
   - G1=45.77%证明框架和分类器有效
   - Demo和`gen_l2_poses.py`的输出处理差异导致关节映射错误

3. **L3框架已验证有效**
   - ST-GCN + 滑动窗口设计正确
   - 9518训练窗口 + 跨subject验证科学
   - G1基准建立，可用于未来L2修复后的对比

## 🔧 修复建议

### 短期方案（1小时）：修复L2后处理
对比Demo和`gen_l2_poses.py`的模型输出处理：
1. 添加翻转增强（TTA）
2. 添加相机坐标转换
3. 验证17关节映射顺序

预期修复后：
- L2骨长ratio → 1.0左右
- G2' → 35-42%（略低于G1，但显著高于随机）

### 长期方案（2-3小时）：不变特征方案
使用pairwise距离特征（272维）：
- 对关节顺序/尺度/旋转完全不变
- 44K参数MLP替代ST-GCN
- 绕过所有后处理问题

预期结果：
- G1' = 40-50%（pairwise特征）
- G2' = 35-45%（即使L2关节顺序错，距离矩阵仍正确）
- Δ' = 5-10%（反映L2的P1误差对动作识别的影响）
